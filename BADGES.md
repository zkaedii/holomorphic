## Badge Generator Script

Use this Python script to generate custom badges:

```python
def generate_badge(label, message, color, style="for-the-badge"):
    """Generate shields.io badge URL"""
    label = label.replace(" ", "%20")
    message = message.replace(" ", "%20")
    return f"https://img.shields.io/badge/{label}-{message}-{color}.svg?style={style}"

# Examples
print(generate_badge("version", "1.0.0", "blue"))
print(generate_badge("tests", "20 passed", "success"))
print(generate_badge("performance", "6.48M samples/sec", "green"))
```

## Tips for Maximum Impact

1. **Place badges at the top** of README for immediate visibility
2. **Use for-the-badge style** for hero section (larger, more prominent)
3. **Use flat/plastic style** for feature lists (more compact)
4. **Group related badges** (Security together, Performance together)
5. **Keep colors consistent** (Green = good, Red = security/important)
6. **Update regularly** to maintain credibility
7. **Don't overdo it** - 6-12 badges is optimal
8. **Prioritize accuracy** - Only claim what you can back up

## Maintenance

### Regular Updates
- Version badge: Update with each release
- Test badge: Update after test runs
- Security badge: Update after security audits
- Last commit: Auto-updates (if using GitHub badges)

### Verification
Ensure all badges reflect accurate information:
- ✅ Version matches actual release
- ✅ Test counts are current
- ✅ Performance metrics are verified
- ✅ Security scores are from latest audit
